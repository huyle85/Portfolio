Backend for an e-commerce system


  • Framework: FastAPI
  • Database: PostgreSQL
  • Authentication & Security: JWT (JSON Web Tokens), Passlib (Bcrypt)

    • System Description: A high-performance, asynchronous RESTful API backend for an e-commerce platform built with FastAPI and PostgreSQL. The system manages user authentication, dynamic product catalogs, cart processing, and secure checkout workflows. Features include JWT-based role authorization (Admin/Customer), Redis caching for fast product queries, background processing for order notifications via Celery, and seamless integration with third-party payment and shipping providers. Fully containerized with Docker for scalable deployment.

English to Script Translator Tool


  • Language & Runtime: Python, Click / Typer (CLI Framework)
  • AI & NLP: OpenAI API (GPT-4o) / DeepL API, NLTK, Regex
  • Data Formatting: Rich / Colorama (Terminal UI), Pydantic

    • System Description: A lightweight Command-Line Interface (CLI) tool built with Python that automatically parses and translates English text into structured video/movie scripts directly from the terminal. The tool leverages LLM APIs (OpenAI/DeepL) and custom NLP rules to format translations into standard script layouts, including scene headings, character dialogues, and stage directions. Features include custom file-to-file processing (.txt, .docx), interactive terminal prompts with real-time status bars, and configurable output styling.
